Méthodologie & avertissement

Ce document est l'image du comportement réel du code à la date de génération. Il a été produit par parcours direct des composants de page, de la navigation, des routes API, des services et du schéma Prisma.

  • Traçage bout-en-bout : pour chaque information, la chaîne composant → fetch("/api/…") → route API → service → table Prisma est indiquée avec fichier:ligne.
  • Vérification des cibles : chaque lien/route a été vérifié (la page existe ou non).
  • Incohérences : les actions non câblées, routes/pages inexistantes, données jamais alimentées et écarts doc↔code sont listés (§ dédiée + par rôle), triés par sévérité.
  • Reconstitutions d'écran : les maquettes sont reconstruites en HTML/CSS à partir de la structure réelle du code et des libellés i18n FR. Les valeurs numériques sont illustratives (aucune donnée patient réelle) — voir l'étiquette sous chaque maquette.
Convention d'unité glycémique — Depuis l'ADR #32, l'unité canonique de stockage/API est g/L (1 g/L = 100 mg/dL) ; l'affichage convertit selon UserUnitPreferences.unitGlycemia (3=g/L, 4=mg/dL, 5=mmol/L) via src/lib/glucose/units.ts et le hook useGlucoseUnit. Les écarts d'application de cette préférence sont signalés.
